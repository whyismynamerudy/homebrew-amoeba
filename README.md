# Amoeba Homebrew tap

```bash
brew install --cask whyismynamerudy/amoeba/amoeba
```

Update with `brew upgrade --cask amoeba`.

Apple Silicon only. Amoeba isn't signed with an Apple Developer ID, so this cask removes the macOS quarantine flag after install to let it open without a Gatekeeper prompt. macOS may ask you to re-grant folder, accessibility, and screen recording permissions after each update.
